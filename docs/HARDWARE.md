# 硬件、时钟与下载

## 目标与编译配置

工程面向CT107类蓝桥杯单片机开发板，源码使用8051端口、74HC138译码及锁存器控制。含STC专用AUXR、P4、PCA等代码时，目标为STC15F2K60S2；不能因为Keil设备栏显示AT89C52就烧录到AT89C52。

为减少对第三方STC设备数据库的依赖，Keil统一使用标准AT89C52/8052兼容编译配置，源文件自带STC寄存器定义。标准REGX52.H、REG52.H、INTRINS.H、ABSACC.H由合法安装的Keil C51提供。

源码UTF-8无BOM，实际C51构建已通过。旧Keil编辑器如显示中文乱码，请用支持UTF-8的编辑器查看/编辑，再用Keil编译。

## 常用端口

| 功能 | 常见连接 | 说明 |
| --- | --- | --- |
| 锁存数据 | P0 | LED、显示、继电器等通过不同通道复用 |
| 译码选择 | P2.5~P2.7 | 以源代码选择4/5/6/7通道 |
| 矩阵按键 | P3及P4.2/P4.4 | 按具体例程核对行列定义 |
| I2C | P2.0/P2.1 | 以iic.c中的sbit定义为准 |
| DS18B20 | P1.4 | 使用外部供电及适当上拉；当前非阻塞方式不支持寄生供电 |
| DS1302 | 见ds1302.c | 按具体开发板连接核对 |
| 超声波 | P1.0发射、P1.1接收 | 适用于源码对应的板载分立收发电路，不能直接当HC-SR04程序使用 |
| 测频 | T0/P3.4 | NE555输出的跳线按开发板核对 |
| UART | P3.0/P3.1 | 常用串口例程采用11.0592MHz、9600、8N1，勿与独立按键同时占用 |

## 每例配置

每个README和projects.json给出了相应时钟；不是全仓库统一频率。带9600串口的灯光综合例程已把50ms重装值同步为11.0592MHz下的46080计数。

01-modules/13-io-expand与01-modules/21-frequency-timers使用XBYTE存储器映射；其他例程按各自源码采用IO译码控制。开发板跳线/拨码必须对应。

Keil的Clock字段是仿真配置，不能替代STC-ISP中的系统时钟设置。不同开发板外设版本、晶振和时序差异仍需上板核对，单总线和超声波的空循环延时尤其需要验证。

## 下载步骤

1. 确认工程README的时钟、译码方式与外设连接。
2. 在Keil中Rebuild，或选择firmware目录内同名例程的HEX。
3. 使用STC-ISP选择实际芯片、串口和该例程的系统时钟；按开发板要求断电上电下载。
4. 依次检查上电输出、显示、按键和外设；修改后的版本暂未实物验收。
