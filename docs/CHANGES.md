# 修复要点

保留原有函数命名、直接寄存器操作和按键/显示结构，统一UTF-8编码、Tab缩进与工程相对路径。

- 修正未定义的计数变量、函数名大小写和重复定义，补齐工程内头文件依赖。
- 串口发送保存中断使能状态；接收中断与回发处理分开，避免TI反复中断和函数重入。
- ADC与超声波换算在乘法前提升位宽，避免中间结果溢出。
- 修复PWM的0%/100%边界、长按计数回绕、超范围延时实参及段码表错误。
- EEPROM只在计数变化时写入，检查上电数据范围，并加入有界ACK轮询。
- PCF8591切换通道后丢弃首个旧转换结果。
- DS18B20使用非阻塞转换完成检查和CRC校验，通信后恢复原中断状态；当前界面限制到0~99度。
- 恢复部分练习中被注释的采集操作，修正移动量计算、频率取样、参数页修改及显示范围。
- 修正定时器重装值；带9600串口的灯光模块统一按11.0592MHz配置相应时间基准。

各工程的实际功能、系统时钟和验证范围以对应README为准；硬件时序与完整原题符合性仍需实测。
