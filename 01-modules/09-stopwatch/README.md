# 09-定时器的进阶综合案例

分钟、秒与节拍显示，按键控制启停和清零。

## 工程与配置

- 主程序：[main.c](main.c)；Keil工程：[project.uvproj](project.uvproj)，目标 `Practice`。
- 适用硬件：CT107类蓝桥杯51开发板，STC15F2K60S2及与源码连接一致的外设。
- 本例时钟：**12 MHz**，下载时按此设置STC系统时钟；工程Clock只影响仿真，不能改变实际芯片时钟。
- 板级译码方式：**IO锁存控制**。跳线/拨码按开发板版本核对。
- 编译器：Keil C51 9.59；工程选择AT89C52作为通用8052兼容编译配置，STC专用寄存器由源码定义。
- 验证状态：已实物验证通过。
- 本次电脑验证：0个编译错误，0个告警。

| `S5` | P3.2 |

## 使用与检查

1. 按[硬件说明](../../docs/HARDWARE.md)核对芯片、译码模式和时钟。
2. 用Keil打开本目录工程，Rebuild生成 `build/firmware.hex`。
3. 也可使用[本次生成的HEX](../../firmware/01-modules/09-stopwatch/firmware.hex)；固件对应当前源码，已实物验证通过。
4. 按主程序的按键处理/主循环操作，检查显示、按键响应、采集和输出是否符合上述功能。
5. 含温度采集时，需外部供电DS18B20；转换未完成或CRC失败会保留上次温度，初始显示可能为0。

软件延时不作为精密时间基准；使用时按本例配置核对系统时钟与接线。
